Goal

Independent AI-assisted proof exercise using three invented optimizer runs and four checkpoints. SQL source and retained outputs make the design inspectable. This is independent proof work, not employment or production experience.

Setup

Use this folder as the working directory. Python uses its standard library. Database execution requires an existing authorized local PostgreSQL database and psql on PATH; this public package includes no binaries, credentials or cluster.
